안녕하세요! 오늘은 백준 온라인 저지의 1225번 문제, "이상한 곱셈"에 대해 알아보겠습니다. 이 문제는 두 숫자의 각 자리 숫자를 곱한 모든 조합의 합을 구하는 것으로, 큰 숫자에서도 효율적으로 해결할 수 있는 방법을 찾는 것이 중요합니다. 이제 문제를 자세히 살펴보고, 효과적인 해결 방법을 찾아보겠습니다.

이 글을 읽고 나면 다음을 할 수 있다. 이중 합을 합의 곱으로 바꾸는 분배법칙을 설명하고, 이 변환으로 O(N·M)이 O(N+M)이 되는 이유와 결과 자료형 범위(최대 8.1×10⁹)를 계산해 낼 수 있다.

문제 : [https://www.acmicpc.net/problem/1225](https://www.acmicpc.net/problem/1225)

## 문제 설명

두 개의 비음수 정수 A와 B가 주어질 때, 전통적인 곱셈 방식과는 다른 "이상한 곱셈"을 정의하려고 한다. 이 "이상한 곱셈"은 A의 각 자리 숫자와 B의 각 자리 숫자를 하나씩 선택하여 곱한 후, 가능한 모든 조합의 합을 계산하는 것이다. 예를 들어, A = 121이고 B = 34일 때:

```
1×3 + 1×4 + 2×3 + 2×4 + 1×3 + 1×4 = 28
```

즉, A가 n자리, B가 m자리 숫자라면 총 n×m개의 곱셈 조합이 존재하며, 이들의 합이 "이상한 곱셈"의 결과가 된다. 주어진 A와 B는 각각 최대 10,000자리의 숫자이므로, 효율적인 계산 방법이 요구된다.

## 접근 방식

이 문제를 효율적으로 해결하기 위해서는 모든 자리 숫자를 직접 곱한 후 합산하는 방식보다는, 두 숫자의 각 자리 숫자의 합을 구한 후 이를 곱하는 방법을 사용하는 것이 효과적이다. 이는 다음과 같은 수학적 사실에 기반한다:

\[
\left(\sum_{i=1}^{n} a_i\right) \times \left(\sum_{j=1}^{m} b_j\right) = \sum_{i=1}^{n} \sum_{j=1}^{m} (a_i \times b_j)
\]

즉, A의 모든 자리 숫자의 합과 B의 모든 자리 숫자의 합을 각각 구한 후, 이를 곱하면 "이상한 곱셈"의 결과를 얻을 수 있다. 이 방법은 두 숫자의 길이에 상관없이 O(N + M)의 시간 복잡도로 문제를 해결할 수 있어 매우 효율적이다.

## C++ 코드와 설명

다음은 최적화된 C++ 코드와 그에 대한 설명이다.

```cpp
#include <iostream>
#include <string>

using namespace std;

int main(){
    string A, B;
    cin >> A >> B;

    // A 또는 B가 "0"인 경우 결과는 0
    if(A == "0" || B == "0"){
        cout << "0";
        return 0;
    }

    // A의 각 자리 숫자의 합 계산
    long long sum_a = 0;
    for(char c : A){
        sum_a += (c - '0');
    }

    // B의 각 자리 숫자의 합 계산
    long long sum_b = 0;
    for(char c : B){
        sum_b += (c - '0');
    }

    // 결과 계산 및 출력
    long long result = sum_a * sum_b;
    cout << result;
}
```

### 코드 설명

핵심은 입력을 숫자가 아니라 문자열로 받는 것이다. 각 수가 최대 10,000자리라 어떤 정수형에도 담기지 않으므로, 문자열의 각 문자에서 `'0'`을 빼 자릿수 값을 얻고 곧바로 누적한다. 합은 한 수당 최대 9×10,000 = 90,000이고 곱은 최대 8.1×10⁹이라 `int`(약 2.1×10⁹)를 넘으므로 누적 변수와 결과는 `long long`으로 둔다. "0" 분기는 최적화가 아니라 가독성용이며, 없어도 자릿수 합이 0이라 곱이 자연히 0이 된다.

## C++ without library 코드와 설명

이번에는 C++의 표준 라이브러리를 사용하지 않고, `stdio.h`, `string.h`, `stdlib.h`만 사용하여 최적화된 코드를 작성해보겠다.

```cpp
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

int main(){
    char A[10005], B[10005];
    scanf("%s %s", A, B);

    // A 또는 B가 "0"인 경우 결과는 0
    if(strcmp(A, "0") == 0 || strcmp(B, "0") == 0){
        printf("0");
        return 0;
    }

    // A의 각 자리 숫자의 합 계산
    long long sum_a = 0;
    int lenA = strlen(A);
    for(int i=0; i < lenA; i++){
        sum_a += (A[i] - '0');
    }

    // B의 각 자리 숫자의 합 계산
    long long sum_b = 0;
    int lenB = strlen(B);
    for(int i=0; i < lenB; i++){
        sum_b += (B[i] - '0');
    }

    // 결과 계산 및 출력
    long long result = sum_a * sum_b;
    printf("%lld", result);
}
```

### 코드 설명

로직은 C++ 버전과 같고 달라지는 것은 메모리 관리뿐이다. 문자열 객체 대신 크기 10,005인 `char` 배열(10,000자리 + 널 문자 + 여유)에 `scanf("%s")`로 읽는다. 배열이 고정 크기이므로 입력이 제약을 지킨다는 가정에 기댄다. `strlen`은 매 호출마다 널 문자까지 훑는 O(길이) 연산이라 반복 조건에 넣으면 O(N²)이 될 수 있어, 루프 밖에서 한 번만 구해 둔다.

## Python 코드와 설명

마지막으로, Python을 사용한 최적화된 코드와 그에 대한 설명이다.

```python
A, B = input().split()

# A 또는 B가 "0"인 경우 결과는 0
if A == "0" or B == "0":
    print(0)
else:
    # A의 각 자리 숫자의 합 계산
    sum_a = sum(int(c) for c in A)
    # B의 각 자리 숫자의 합 계산
    sum_b = sum(int(c) for c in B)
    # 결과 계산 및 출력
    print(sum_a * sum_b)
```

### 코드 설명

Python은 정수 크기에 제한이 없어 오버플로우를 걱정할 필요가 없다. `sum(int(c) for c in A)`로 자릿수 합을 한 줄에 구하고 곱을 출력한다. 달라지는 점은 언어 특성뿐이며 알고리즘은 같다.

## 복잡도 비교

| 방식 | 시간 복잡도 | 공간 복잡도 | 비고 |
|---|---|---|---|
| 모든 자릿수 쌍을 곱해 합산 | O(N·M), 최대 10⁸회 곱셈 | O(1) | 제한 시간 안에 들 수는 있으나 불필요하다 |
| 자릿수 합의 곱 | O(N+M), 최대 2×10⁴회 덧셈 | O(1) (입력 문자열 제외) | 분배법칙으로 정당화된다 |

## 흔한 오해

"0이 들어오면 따로 처리해야 한다"는 생각이 흔하지만, 자릿수 합이 0이면 곱이 0이므로 특수 분기는 필요 없다. 또 "자릿수 합의 곱은 두 수의 곱과 같다"고 착각하기 쉬운데, 이 문제의 "이상한 곱셈"은 자릿수 위치를 무시하므로 일반 곱셈과 다르다. 예컨대 121×34 = 4114지만 이상한 곱셈의 결과는 (1+2+1)×(3+4) = 28이다.

## 결론

모든 자릿수 쌍의 곱을 합한 값은 분배법칙에 따라 두 자릿수 합의 곱과 같다는 사실 하나로 O(N·M) 문제가 O(N+M)이 된다. 합이 곧바로 전체 곱 조합의 합을 대신한다는 점, 그리고 결과가 32비트를 넘을 수 있다는 점이 이 문제의 전부다. 이런 "이중 합을 곱으로 분리"하는 변환은 합의 구조가 곱셈에 대해 분리 가능할 때 일반적으로 쓸 수 있다.

## 코너 케이스 및 실수 포인트

| 케이스 | 설명 | 처리 방법 |
|---|---|---|
| **0이 포함된 입력** | `0 0` 또는 한쪽이 0 | 자릿수 합이 0이므로 곱도 0, 별도 분기 불필요 |
| **최댓값** | 두 수 모두 9가 10,000개 → 90,000×90,000 = 8.1×10⁹ | `long long` 사용 (`int`는 오버플로우) |
| **C 배열 크기** | 10,000자리 + 널 문자 | 최소 10,001 이상, 여기서는 10,005 |
| **`strlen` 반복 호출** | 루프 조건에 넣으면 O(N²) 가능 | 루프 밖에서 한 번만 호출 |
