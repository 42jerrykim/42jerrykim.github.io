폰 노이만과 파리는 알고리즘 문제를 통해 천재적인 사고방식을 탐구할 수 있는 흥미로운 주제이다. 이번 포스팅에서는 백준 14924번 문제 "폰 노이만과 파리"를 중심으로 문제를 설명하고, 효율적인 풀이 방법을 제시하고자 한다.

문제 : [https://www.acmicpc.net/problem/14924](https://www.acmicpc.net/problem/14924)

## 문제 설명

역사상 최고의 천재 중 하나로 손꼽히는 폰 노이만에게는 흥미로운 일화가 전해진다. 어느 날, 그의 동료는 폰 노이만의 천재성을 시험해보기 위해 다음과 같은 문제를 던졌다.

"200마일 길이의 철로의 양쪽 끝에 서 있는 두 대의 기차가 시속 50마일의 속도로 서로를 향해 출발했습니다. 이때부터 두 기차가 서로 충돌할 때까지 파리가 시속 75마일의 속도로 두 기차 사이를 왔다 갔다 했습니다. 파리가 이동한 거리는 모두 몇 마일일까요?"

이 일화에서 폰 노이만은 곧바로 150마일이라고 답했고, 동료가 "무한급수를 쓰는 요령을 알고 있었군요"라고 하자 "아니요, 급수를 그냥 합했습니다"라고 답했다고 전해진다. 즉 지름길을 쓴 것이 아니라 급수를 암산으로 합산했다는 쪽이 널리 알려진 판본이며, 일화의 세부는 출처마다 다르다([John von Neumann, Wikipedia](https://en.wikipedia.org/wiki/John_von_Neumann)에도 이 문제가 소개되어 있다). 어느 쪽이든 이 문제는 급수와 상대속도, 두 가지 풀이가 같은 답에 도달한다는 점이 핵심이다.

이 문제를 일반화하여, 두 기차의 속도 `S`, 파리의 속도 `T`, 그리고 처음 두 기차 사이의 거리 `D`가 주어질 때, 두 기차가 만날 때까지 파리가 이동한 거리 `F`를 계산하는 프로그램을 작성하는 것이 목표이다. 단, `T > S`이며, `D`는 `2*S`의 배수로 주어진다.

## 이 글을 읽은 후 달성할 목표

- 파리가 몇 번 왕복하는지 세지 않고, 기차가 만날 때까지의 시간만으로 이동 거리를 구할 수 있다.
- 무한급수 풀이와 상대속도 풀이가 같은 값을 주는 이유를 설명할 수 있다.
- 입력 범위로부터 `int` 자료형으로 충분한 근거와 정수 나눗셈이 안전한 근거를 말할 수 있다.

## 접근 방식

이 문제를 해결하기 위해서는 두 기차가 만날 때까지 걸리는 시간을 먼저 계산하고, 그 시간 동안 파리가 이동한 거리를 구하면 된다. 두 기차는 서로를 향해 동일한 속도로 움직이므로, 두 기차가 만나는 시간은 처음 거리 `D`를 두 기차의 속도 합인 `2*S`로 나눈 값이 된다.

파리는 이 시간 동안 시속 `T`마일의 속도로 이동하므로, 이동한 거리 `F`는 `T`와 만나는 시간의 곱으로 계산할 수 있다.

즉, 
```
시간 = D / (2 * S)
F = T * 시간
```

이러한 단순한 계산을 통해 문제를 효율적으로 해결할 수 있다. 무한급수를 사용하지 않아도 되므로, 시간 복잡도는 `O(1)`이다.

### 무한급수 풀이와의 비교

파리는 `T > S`이므로 매번 반대편 기차에 닿고 방향을 바꾼다. 첫 구간에서 파리와 맞은편 기차는 서로 `T + S`의 속도로 가까워지므로 첫 구간의 길이는 `D·T/(T+S)`이고, 이후 구간은 남은 간격이 일정한 비율로 줄어드는 등비수열을 이룬다. 파리는 방향을 바꾸는 횟수가 무한하지만 구간 길이의 합은 유한하며, 등비급수의 합을 구하면 `D·T/(2S)`가 된다. 이는 상대속도 풀이의 `T · D/(2S)`와 정확히 같다. 상대속도 풀이는 "파리가 방향을 바꾸는 횟수"라는 세부 사정이 최종 거리에 영향을 주지 않는다는 점을 이용해 급수 자체를 없앤다.

### 흔한 오개념

- 파리의 왕복 횟수를 세거나 시뮬레이션하려는 시도는 불필요하다. 횟수는 무한이고 필요한 정보도 아니다.
- 파리의 속도를 기차 속도와 더하거나 빼서 만나는 시간을 구하는 것은 오류다. 만나는 시간은 두 기차의 접근 속도 `2S`만으로 결정된다.

### 복잡도

| 구분 | 값 | 이유 |
|---|---|---|
| 시간 복잡도 | `O(1)` | 나눗셈과 곱셈 한 번씩 |
| 공간 복잡도 | `O(1)` | 변수 `S`, `T`, `D`, `F`만 사용 |

## C++ 코드와 설명

아래는 문제를 해결하는 최적화된 C++ 코드이다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    
    int S, T, D;
    cin >> S >> T >> D;
    
    // 두 기차가 만나는 시간 계산
    int time = D / (2 * S);
    
    // 파리가 이동한 거리 계산
    int F = T * time;
    
    cout << F;
}
```

### 코드 설명:
`S`, `T`, `D`를 입력받아 만나는 시간 `time = D / (2 * S)`를 구하고, 파리의 이동 거리 `F = T * time`을 출력한다. 문제에서 `D`가 `2*S`의 배수로 보장되므로 정수 나눗셈의 나머지가 생기지 않아 `time`이 정확히 떨어진다.

### 예제:
입력:
```
50 75 200
```
출력:
```
150
```
이 예제에서 `D / (2 * S)`는 `200 / 100`이므로 두 기차는 2시간 후에 만나며, 파리는 이 시간 동안 150마일을 이동하게 된다.

## C++ without library 코드와 설명

아래는 `stdio.h`만을 사용하여 작성한 최적화된 C++ 코드이다.

```cpp
#include <stdio.h>

int main(){
    int S, T, D;
    scanf("%d %d %d", &S, &T, &D);
    
    // 두 기차가 만나는 시간 계산
    int time = D / (2 * S);
    
    // 파리가 이동한 거리 계산
    int F = T * time;
    
    printf("%d", F);
}
```

### 코드 설명:
위 C++ 코드와 계산식은 같고, 입출력만 `scanf`/`printf`로 바꾸었다. 이 코드는 C++ 표준 라이브러리를 사용하지 않고도 동일한 논리를 구현하였다.

## Python 코드와 설명

아래는 문제를 해결하는 최적화된 Python 코드이다.

```python
def main():
    S, T, D = map(int, input().split())
    
    # 두 기차가 만나는 시간 계산
    time = D // (2 * S)
    
    # 파리가 이동한 거리 계산
    F = T * time
    
    print(F)

if __name__ == "__main__":
    main()
```

### 코드 설명:
`input().split()`과 `map`으로 세 정수를 읽고, 같은 식을 `//` 정수 나눗셈으로 계산한다. 예제 `50 75 200`의 결과는 위와 같이 150이다.

## 코너 케이스 및 실수 포인트

| 케이스 | 설명 | 처리 방법 |
|---|---|---|
| **입력 형식** | 한 줄에 `S T D` 세 정수 | 입력 개수가 고정이므로 반복문 없이 한 번만 읽는다 |
| **오버플로우** | S, T, D ≤ 10,000이면 답은 최대 약 5×10^7 | `int`(최대 약 2.1×10^9)로 충분하며 `long long`은 필요 없다 |
| **정수 나눗셈** | D는 2S의 배수 | `D / (2 * S)`가 정확히 떨어지므로 반올림 오차가 없다 |

## 결론

입력 조건이 명확하게 주어졌기 때문에 별도의 예외 처리는 필요하지 않다. 같은 방식은 "움직이는 대상의 경로가 복잡해도 총 시간을 먼저 구한다"는 형태의 문제에 응용할 수 있다.
