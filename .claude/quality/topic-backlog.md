# 주제 백로그 (Topic Backlog)

"사람들이 찾는데 글이 없거나 약한 주제"의 큐다. [`engagement-report`](../skills/engagement-report/SKILL.md) 스킬이 [`engagement.md`](engagement.md)의 검색 데이터에서 후보를 도출해 여기에 추가하고, 사람이 승인한 항목만 [`blog-agent-pipeline`](../skills/blog-agent-pipeline/SKILL.md)으로 작성에 들어간다.

- **상태 값**: `후보`(AI 제안) / `승인`(사람이 작성 결정) / `작성중` / `게시` / `기각`
- **항목 유형**: `신규 글` / `기존 글 개선`(제목·description·본문 보강 — URL은 바꾸지 않는다)
- **근거 규칙**: 모든 항목은 근거 데이터(검색어·노출·클릭 등)를 함께 적는다. 근거 없는 "쓰면 좋을 것 같은 주제"는 여기 넣지 않는다.
- **안전 원칙**: 백로그 추가는 AI가 하되, `후보` → `승인` 전환은 사람만 한다. 클릭을 늘리기 위한 과장 제목(클릭베이트)은 기존 글 개선 항목에서도 금지 — 제목은 본문이 실제로 답하는 질문을 정확히 반영해야 한다.
